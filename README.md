## Random Item Speedrun

This mod tests the player's gear by forcing them to collect one randomly selected item

![preview](https://i.postimg.cc/Bb69YrRm/Random-Item1.png)

## Usage

After installing the mod, press the Y key (default) to open the run start screen. This screen displays a list of speedruns and additional information about each run by tapping on the desired run. To start a speedrun, press the corresponding button, and the item you need to collect will appear on the screen. For more accurate run information, the item name and elapsed time will be displayed in the corner of the screen.

The mod has settings where you can change the HUD parameters (more customization options are planned for the future).

![preview](https://cdn.modrinth.com/data/le0FiAgt/images/caf8291d75e76e4833b9b84a645b15191769ba4f.png)

Since version 2.0, the mod has been running on the server. This means all players can participate in the same run simultaneously. The name of the player who finds the item will also be saved in the run list.

You can specify the difficulty of drop items in the mod settings:
* **Easy** - items that don't require entering the Nether,
* **Normal** - items that don't require entering the End,
* **Hard** - all items except those that take too long to obtain,
* **Hardcore** - all items.

To start/stop the game without entering the mod screen, you can assign a key in the binding settings. Pressing the key will then instantly change the game status.
